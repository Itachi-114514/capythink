# 卡皮思 · CapyThink（工具版）

把想不通的问题，先问自己一次。

一个匿名的哲学自测工具：30 条陈述，四个选项，可跳过；做完给你一张六维图、一段画像，和五本按你现在的状态挑的书。书库 240 本。

**不注册、不收邮箱、不做匹配。** 答案和结果只存在你自己的浏览器里。整个站点是纯静态导出，没有数据库、没有后端接口、没有邮件服务。

---

## 跑起来

需要 Node 20 以上。

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

构建：

```bash
pnpm build      # 产物在 out/
```

本地预览静态产物（任选一种）：

```bash
python -m http.server 8080 -d out
# 或 npx serve out
```

## 部署

把 `out/` 整个目录传到静态托管即可：对象存储（OSS / COS）、CDN、或者一台 Nginx。

Nginx 最小配置：

```nginx
server {
  listen 443 ssl;
  server_name yourdomain.com;
  root /var/www/capythink/out;
  index index.html;

  location / {
    try_files $uri $uri/ =404;
  }
}
```

因为开了 `trailingSlash`，`/quiz/` 对应 `out/quiz/index.html`，直接按目录访问即可。HTTPS 用 certbot 签。

## 上线前：填备案信息

只改一个文件：`src/site.config.ts`。

- `icp`：备案号，例如「京ICP备2026000000号-1」，会出现在页脚并链接到工信部备案系统。
- `police`：公安备案号，可选，同样会出现在页脚。
- `contactEmail`：对外联系邮箱，会出现在隐私页。

留空就不渲染，所以现在站点看起来没有变化。填完重新 `pnpm build`，再上传 `out/`。

Cloudflare Pages 等境外托管不需要备案，`icp` 和 `police` 保持空即可，见 `deploy/CLOUDFLARE.md`。

## 数据

| 键名 | 内容 |
| --- | --- |
| `capythink.draft.v1` | 答题进度（答案、当前题号、阶段） |
| `capythink.result.v1` | 最近一次的结果与书单 |
| `capythink.history.v1` | 每次测验的记录（最多 30 条） |
| `capythink.shelf.v1` | 书架标签和书的信息快照 |

结果页有「清除这份结果」，也可以直接清除浏览器的站点数据。没有服务器备份，清了就没了。

## 我的记录

- `/me` 每次提交测验都会存一条记录，包含当次结果和书单。
- 每本推荐书可以贴「准备读 / 正在读 / 已经读完」；再点一次当前标签可以取消。
- 贴过标签的书（准备读、正在读、已经读完），下次测验推荐时都会跳过；取消标签后重新进入候选。
- 每本书可以写一句感想（最多 120 字）；标成「已经读完」时会自动填当天日期，也可以手动改。
- 写过的感想会在「笔记」里按月排成时间线，「统计」按月统计读完数量。
- 书库卡片会标「已写感想」，也可以按这个状态筛选。
- 「变化」里有六维折线图和「和上次相比」；差值小于两次测量合成误差时标成 ≈，不当作真实变化。
- 「导出备份」把历史、书架和最近结果写成一个 JSON；「导入备份」会覆盖当前记录，用于换设备或清缓存前迁移。
- 记录和标签都在浏览器里，换设备或清缓存不会自动同步，所以备份要自己存好。

## 分享图

结果页底部有「保存分享图」，生成 1080×920 的 PNG：人格、插图和画像，不包含书单和六维图。Chrome / Edge 会弹出「另存为」，其他浏览器下载到默认下载文件夹。

## 书库

`/books` 列出全部 240 本，可以按六个维度、方向、难度、地区、标签和书架状态筛选，也支持搜索、排序和「再显示 48 本」。卡片上可以直接贴「准备读 / 正在读 / 已经读完」，和「我的记录」共用同一份书架数据。

## 改题目和书

题目在 `data/questions.ts`。每条陈述有 `dim`（属于哪一维）和 `pole`（同意时指向哪一极），计分只认 `pole`，不要用原题的 `(R)` 标记直接翻转。

书在 `data/books-*.ts`。加书时填 `dims`（1–3 个维度标签，weight 0.3–1）、`difficulty`（1–5）、`tags`；`books-all.ts` 会按「书名 + 作者」去重。

## 12 种人格

结果标题只取最强的一维，一共 12 种：

| 维度 | 负端 | 正端 |
| --- | --- | --- |
| 知识来源 | 先验主义者 | 经验主义者 |
| 道德判断 | 义务论者 | 后果论者 |
| 世界构成 | 观念论者 | 唯物论者 |
| 决定与自由 | 决定论者 | 自由意志论者 |
| 意义来源 | 自赋意义者 | 本质主义者 |
| 确定与怀疑 | 独断论者 | 怀疑论者 |

- 最强维的绝对值 < 0.3 → 还没定型的提问者
- 六个维全跳过 → 还在潜水的提问者
- 同分时取标准误更小（回答更一致）的那一维，不再按固定顺序硬选
- 前两维很接近时，结果页会标出「把握：低 / 中 / 高」和第二名
- 正文仍然按最强三维生成，不只有一句标签

名字都在 `src/lib/types.ts` 的 `DIM_META.nouns` 里，想改直接改。

## 结果的可信度

- 分数条上的浅色阴影是 ±1 个近似标准误（5 题内部离散度 ÷ √题数），不是置信区间，也不是百分位。
- 类型把握程度由前两维差距和误差范围比较得出：小于 1 个误差算低，小于 2 个算中，否则算高。
- 没有常模，没有做过信效度检验；12 种人格是摘要，不是诊断。详细说明在 `/methods`。

## 备案与合规

- 这个版本不收集邮箱、不注册、不做用户间联系，页面里也没有「匹配 / 交友 / 社交」字样。
- 境内托管需要个人备案；Cloudflare 等境外托管不需要备案，此时 `site.config.ts` 的 `icp` 留空，页脚不要写备案号。
- 如果走境内备案，通过后把备案号和联系邮箱填进 `src/site.config.ts`，重新构建；页脚和隐私页会自动更新。
- 文案避免「教育 / 课程 / 培训 / 教学」——教育属于前置审批项，个人基本拿不到。
